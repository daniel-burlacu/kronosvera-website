# KronosVera Vite + Material UI Website

Simple static presentation website for KronosVera.

## Tech

- Vite
- React
- TypeScript
- Material UI
- Component-based structure
- White background
- Local image assets

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is created in `dist/`.
